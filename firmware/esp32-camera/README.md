## 当前目标与范围

原有 ESP32-CAM 算力不足，当前研究以 **ESP32-S3 N16R8** 为主控，在该 ESP 上部署模型的可行性。
相机采集是模型输入验证的一部分；当前任务已从单张拍照扩展到模型部署与推理研究。

与 **Zhang Haoyu** 的[模型训练研究](../../models/README.md)对接，确认模型、输入输出及导出要求。
本目录目前保存任务说明，不代表已有可用模型、部署固件或通过实测的性能结果。

**RDK X5 + NPU** 是另一条候选主控路线，是否探索等待 **Dr Davy Ng consult** 后决定；当前不将其纳入本任务的必做交付。

## 研究交付

1. 核实实际 ESP32-S3 N16R8 开发板、摄像头、存储配置与开发环境，记录仍待确认的项目。
2. 研究候选模型的板上运行方式，记录部署工具链、模型格式、支持与不支持的操作，以及转换或量化需求；尚未验证的兼容性必须注明。
3. 与 Haoyu 对齐输入尺寸、预处理、输出含义、导出格式、模型大小和运行时资源约束；平台限制有变化时同步训练端。
4. 记录已完成的最小实验：模型转换、构建／烧录、输入获取、单次推理及结果读取；相机输入可先验证初始化与单张拍照，再接入推理。
5. 对实际运行的实验记录模型版本、内存／存储占用、推理延迟或帧率、输出表现和失败日志。没有上板时写明「未做板上验证」，不填预期性能作为实测。
6. 给出可行性结论、阻碍和下一步建议，附复现步骤；发现目标模型无法运行或资源不足，也应保留实验依据供方案决策。
