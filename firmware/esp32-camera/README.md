## 交付与验收

1. 提交与实物匹配的摄像头初始化和单张拍照最小示例。
2. 完整运行一次初始化、拍照及获取照片流程，照片能在电脑或浏览器中正常打开。
3. 记录获取照片的方法、实际图片格式／分辨率及成功或失败的日志。
